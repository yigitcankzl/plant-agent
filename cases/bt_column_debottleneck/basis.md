# Benzene–toluene column: data sheet

ILLUSTRATIVE equipment ratings on the standard equimolar benzene–toluene teaching column. Bubble points, duties and
the stage profile below were solved in this install of DWSIM with Peng–Robinson. They are not a published plant test.
Normal boiling points of the pure components (benzene 80.1 C, toluene 110.6 C) are public physical data.

## Feed

| Item | Value |
|---|---|
| Flow | 3,064 kg/h (10 mol/s) |
| Composition | equimolar benzene and toluene |
| Temperature | 92 C |
| Pressure | 1.013 bar(a) |

## Column C-101

| Item | Value |
|---|---|
| Stages | 12, including a total condenser (stage 1) and a kettle reboiler (stage 12) |
| Feed stage | 7 (counted from the condenser) |
| Pressure | 1.01325 bar(a) at the top, no column pressure drop |
| Condenser | total |
| Reflux ratio | 2.0 |
| Bottoms product | 5.0 mol/s (half the feed molar flow; scale this with the feed) |
| Shell inside diameter | 0.80 m (ILLUSTRATIVE) |
| Tray spacing | 0.50 m (ILLUSTRATIVE) |
| Design flood | 80% of Fair's entrainment flood |
| Condenser E-101 | 600 kW (ILLUSTRATIVE) |
| Reboiler E-102 | 600 kW (ILLUSTRATIVE) |

At the base rate DWSIM reports distillate about 1,420 kg/h at 80.9 C (about 1,325 kg/h benzene) and bottoms about
1,644 kg/h at 108 C. Condenser duty is about 460 kW and reboiler duty about 465 kW. The Fair screen on the reported
stage traffic, with the illustrative 0.80 m shell and 0.50 m tray spacing, is a flood fraction of about 0.69
(utilisation 0.86 of the 0.80 limit).
