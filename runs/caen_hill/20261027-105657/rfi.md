# Step 2 - Requests for information and assumptions

| item | issue | resolution | reason |
|---|---|---|---|
| Duty configuration and firm capacity definition | Installed vs operated duty: Table 1 says Duty/Assist but control says both parallel duty/duty fixed speed | ASSUMPTION: assess both single-pump as firm capacity and two-pump parallel as installed peak; reason - site tests and SCADA cover both modes and report derives both operating points | Conflict affects which flow is firm and how efficiency/POR assessed |
| Test head and static head basis | Raw suction/delivery pressures, wet-well depths and GPS elevations not tabulated in summary; only derived curves and Table 3/4 summaries shown | ASSUMPTION: adopt reported datums (wet well 55.5 mAOD, pump CL 54.3 mAOD, discharge 127.6 mAOD = ~72 m static rise) as static basis; reason - these are the only quoted levels and rise matches 72 m | Cannot independently recompute system curve without raw heads |
| Unexplained rising-main loss | Extra K=120 to match SCADA delivery pressure on <25-yr ductile iron main - roughness, air, partial blockage or valve loss not separated | ASSUMPTION: treat K=120 as anomaly to be quantified with simulator vs clean-pipe friction; reason - report flags it as concern requiring high loss coefficients | Core energy-loss quantification needs split between normal friction and anomaly |
| NRV operability for surge and head loss | Intermediate NRVs condition unknown, buried under concrete covers in remote towpath, not inspected | ASSUMPTION: model worst case as failed open (not operational) for surge diagnosis and as potential loss/blockage source; reason - report does this and notes high transients on that assumption | Surge peaks and system curve depend on whether NRVs hold or stand open |
| Flow measurement accuracy | Flow from existing electromagnetic flowmeter, calibration/uncertainty and SCADA estimation method for 2018 daily volumes not stated | ASSUMPTION: accept meter as reference for audit with noted uncertainty; reason - same meter used for test and SCADA correlation | Energy and system-curve conclusions rely on this meter but it is not used for control |
| Electrical efficiency split and overload | Power only at VSD input via temporary Fluke; separate VSD, motor and pump efficiencies not given; 224 kW reading exceeds 215 kW motor rating | ASSUMPTION: use reported wire-to-water STRING efficiency for comparisons; reason - defined as including VSD and is the only consistent metric | Cannot isolate VSD vs motor vs pump loss without nameplate curves |
| NPSH calculation detail | NPSH ~4 m margin calculation inputs (levels, vapour pressure, suction losses with silted screens) not shown | ASSUMPTION: accept ~4 m margin as calculated and pursue blockage/silt/vorticity as cavitation-mark causes; reason - report explicitly rules out NPSHa as root cause on that basis | Cannot verify cavitation vs blockage conclusion |
| Applicable vibration limit and method deviation | Vibration limits: BS ISO excludes submersibles, WIMES has no 2-vane class; magnetic temporary transducer not on bearing housing per WIMES 70-120% BEP protocol | ASSUMPTION: adopt 11.2 mm/s RMS as reasonable acceptance limit for 2-channel pump; reason - report justification, and all tests significantly exceed it regardless of method | Need a defensible pass/fail despite standard gaps |
| Allowable surge pressure | Pipe/manifold pressure rating and gasket specification not stated, yet gasket failures and 13-20 bar.g surge peaks reported | ASSUMPTION: treat calculated peaks comparatively as evidence of slam risk, rating to be confirmed by CRT; reason - report links ball-valve slam, untied adaptors and residual moments to failures | Cannot judge if peaks explain gasket failures without rating |
| Control setpoints and foundation fixity | Lock 50 low/high level setpoints, ramp details beyond 30 s, and plinth/foundation fixity quantities (torques, grout, crack widths) not given | ASSUMPTION: use fixed 48 Hz parallel level control as described and qualitative poor-anchorage evidence (comparable plate vibration, cracking/seepage, touch test); reason - only evidence quoted, intrusive investigation still required as high priority | Optimisation and re-anchoring design need these |
